# سیستم مدیریت آموزش (LMS)

این پروژه یک سیستم مدیریت آموزش جامع است که با استفاده از فریم‌ورک **Django** و زبان **Python** و دیتابیس **SQL Server** توسعه یافته است.

## ✨ امکانات پروژه
- مدیریت کامل (CRUD) برای دانشجویان، اساتید، دوره‌ها و دسته‌بندی دوره‌ها.
- سیستم ثبت‌نام دانشجو در دوره‌های آموزشی.
- ثبت و مدیریت نمرات دانشجویان.
- صدور مدارک برای دوره‌ها.
- تقویم آموزشی (نمایش دوره‌ها بر اساس ترم).
- سیستم احراز هویت (ورود / خروج).

## 🛠 پیش‌نیازهای اجرا
- Python نسخه 3.10 به بالا
- SQL Server و SSMS (برای مدیریت دیتابیس)
- ODBC Driver 17 for SQL Server
