# سیستم مدیریت آموزش (LMS)

پروژه‌ای جامع برای مدیریت دوره‌های آموزشی، اساتید و دانشجویان که با فریم‌ورک **Django** و دیتابیس **SQL Server** پیاده‌سازی شده است.

## ✨ امکانات
- مدیریت کامل (CRUD) دوره‌ها، اساتید، دانشجویان و دسته‌بندی‌ها
- فرآیند ثبت‌نام دانشجو در دوره‌ها
- ثبت و مدیریت نمرات
- صدور مدارک
- تقویم آموزشی
- احراز هویت (ورود/خروج)
