# سیستم مدیریت آموزش (LMS)

این پروژه یک سیستم مدیریت آموزش جامع است که با استفاده از فریم‌ورک Django و زبان پایتون توسعه یافته است.

## قابلیت‌ها:
- مدیریت دوره‌ها، اساتید و دانشجویان
- سیستم ثبت‌نام در دوره‌ها
- برگزاری آزمون و ثبت نمرات
- صدور مدارک
- پنل اختصاصی دانشجو و استاد

## نحوه اجرای پروژه:
1. نصب کتابخانه‌های مورد نیاز: `pip install -r requirements.txt`
2. اجرای مایگریشن‌ها: `python manage.py migrate`
3. اجرای سرور: `python manage.py runserver`
